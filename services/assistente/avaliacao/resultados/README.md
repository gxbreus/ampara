# Resultados brutos da avaliação do RAG

Uma pasta por execução do `python -m app.avaliar`, com o nome que o runner dá
(`AAAAMMDDTHHMMSSZ`): `execucao.json`, `respostas.jsonl`, `planilha-cega.csv`,
`gabarito-ab.json` e, com `--latencia`, `latencia.json`. As planilhas preenchidas
pelos dois avaliadores ficam na mesma pasta, como `notas-<avaliador>.csv`.

Os números de `docs/llm/avaliacao-rag.md` precisam bater com estes arquivos.
